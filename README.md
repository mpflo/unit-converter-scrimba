# Unit Converter

A simple unit converter built with HTML, CSS and JavaScript.

## Features

- Convert meters to feet and feet to meters
- Convert liters to gallons and gallons to liters
- Convert kilograms to pounds and pounds to kilograms
- Display results with three decimal places

## Technologies

- HTML
- CSS
- JavaScript

## How to use

1. Enter a number in the input field.
2. Click the **Convert** button.
3. The conversions will be displayed below.
